Guia de Integração da API (Pacotes 1 a 4 • 100% Brasil)

Integração completa de Mensageria, Enquetes Interativas, Atendimento, Grupos, Status 24h e Blindagem Anti-Ban

1. Pacote 1: Mensageria Completa & Interativa

Texto com Citação/Menção/LinkPreview, Áudio PTT Microfone Verde, Enquetes Interativas (substituto oficial de botões), Documentos, Vídeos/PTV, Stickers, Localização, vCard, Reações, Edição e Revogação:

# 1.1 Texto Oficial (com Quote/Reply, Menções, Link Preview e Simulação Digitando)
curl -X POST http://localhost:8080/api/v1/mensagem/texto \
  -H "Content-Type: application/json" -H "x-api-key: {chave_da_instancia}" \
  -d '{
    "destinatario": "11987654321",
    "mensagem": "Olá! Confira seu pedido em https://woohub.com.br",
    "id_mensagem_citada": "3EB0123456",
    "atraso_digitacao_ms": 1500
  }'

# 1.2 Enquete Interativa Nativa (Substituto Oficial 100% Compatível de Botões)
curl -X POST http://localhost:8080/api/v1/mensagem/enquete \
  -H "Content-Type: application/json" -H "x-api-key: {chave_da_instancia}" \
  -d '{
    "destinatario": "11987654321",
    "pergunta": "Com qual setor você deseja falar?",
    "opcoes": ["1. Financeiro / 2ª Via", "2. Suporte Técnico", "3. Comercial"],
    "maximo_selecao": 1
  }'

# 1.3 Documento PDF / Boleto / Nota Fiscal (ou /video, /imagem, /audio, /sticker, /localizacao, /contato)
curl -X POST http://localhost:8080/api/v1/mensagem/documento \
  -H "Content-Type: application/json" -H "x-api-key: {chave_da_instancia}" \
  -d '{
    "destinatario": "11987654321",
    "documento_base64": "JVBERi0xLjQK...",
    "nome_arquivo": "boleto_mensalidade.pdf",
    "legenda": "Segue seu boleto atualizado."
  }'

# 1.4 Reação com Emoji, Edição em Tempo Real e Revogação (Apagar para Todos)
POST /api/v1/mensagem/reacao   {"destinatario":"11987654321","id_mensagem_alvo":"ID_MSG","emoji":"❤️"}
POST /api/v1/mensagem/editar   {"destinatario":"11987654321","id_mensagem_alvo":"ID_MSG","novo_texto":"Texto corrigido!"}
POST /api/v1/mensagem/revogar  {"destinatario":"11987654321","id_mensagem_alvo":"ID_MSG"}

Configuração de Webhook

Receba a assinatura no cabeçalho X-WooHub-Signature-SHA256. Ela é o HMAC-SHA256 do corpo JSON usando este segredo.
Quais dados e eventos o webhook envia?

Todos os eventos usam este envelope:

{
  "instancia_id": "inst_...",
  "nome_instancia": "Principal",
  "evento": "mensagem_recebida",
  "data_hora": "2026-11-04T15:00:00-03:00",
  "dados": { "...": "conteúdo específico do evento" }
}
Eventos disponíveis
  • mensagem_recebida: remetente, mensagem, tipo, texto e mídia.
  • status_envio: mensagem, destinatário e status de entrega.
  • conexao: estado, JID e número conectado.
  • presenca, qrcode, chamada_recebida, voto_enquete, reacao_mensagem e atualizacao_grupo.

O campo dados varia conforme o evento. Consulte os exemplos na documentação da API antes de mapear seu CRM, n8n ou sistema próprio.
