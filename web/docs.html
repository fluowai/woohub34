WooHub API • Documentação Oficial

A API de automação de WhatsApp de mais alto desempenho no Brasil. Construída sobre motor Go nativo, oferece mensageria corporativa, resolução automática de nono dígito brasileiro, proteção anti-ban e suporte completo a agentes de inteligência artificial via MCP.

⚡ Pronto para Agentes de IA via Model Context Protocol (MCP) Open Standard

Conecte o Claude Desktop, Cursor, Antigravity, ChatGPT e agentes LangChain diretamente ao WhatsApp da sua empresa com comandos em linguagem natural. Role até a seção MCP para ver a especificação completa de ferramentas e prompts.

HEADER Métodos de Autenticação

Todas as requisições para a API devem incluir credenciais válidas. Para operações de WhatsApp utilize a chave da instância; para rotas administrativas utilize o Bearer Token JWT.

Header Tipo Escopo Descrição
x-api-key String Instância Chave secreta gerada ao criar a conexão WhatsApp. Usada para envio de mensagens, checagem e grupos.
Authorization Bearer Token Gestão Token JWT retornado em /api/v1/auth/login. Usado para criar instâncias, revendas e consultar financeiro.
POST /api/v1/mensagem/texto x-api-key

Envia uma mensagem de texto com suporte a menções (@usuario), citação/resposta de mensagens anteriores, pré-visualização de links e simulação humana com tempo de digitação.

Campo Tipo Obrigatório Descrição
destinatario string Sim Número com DDD (ex: "11987654321") ou JID de grupo ("120363025987654@g.us").
mensagem string Sim Conteúdo em texto UTF-8 com suporte a formatação (*negrito*, _itálico_, emojis).
id_mensagem_citada string Não ID da mensagem que será respondida com Quote/Citação.
atraso_digitacao_ms int Não Milissegundos simulando presença "digitando..." antes do envio real (ex: 1500). 
curl -X POST https://wooapi.wootech.com.br/api/v1/mensagem/texto \
  -H "Content-Type: application/json" \
  -H "x-api-key: SUA_CHAVE_DE_INSTANCIA" \
  -d '{
    "destinatario": "11987654321",
    "mensagem": "Olá! Seu pedido já está a caminho: https://loja.com/rastreio",
    "atraso_digitacao_ms": 1200
  }'

POST Ações em Mensagens (Reação, Edição e Revogação) x-api-key

Permite reagir com qualquer emoji, editar textos em tempo real após o envio e revogar (apagar para todos) mensagens disparadas. 

# 1. Reagir com Emoji
POST /api/v1/mensagem/reacao
{ "destinatario": "11987654321", "id_mensagem_alvo": "3EB0ABCDEF123", "emoji": "❤️" }

# 2. Editar Texto (até 15 minutos após o envio)
POST /api/v1/mensagem/editar
{ "destinatario": "11987654321", "id_mensagem_alvo": "3EB0ABCDEF123", "novo_texto": "Texto retificado!" }

# 3. Apagar / Revogar para Todos
POST /api/v1/mensagem/revogar
{ "destinatario": "11987654321", "id_mensagem_alvo": "3EB0ABCDEF123" }
POST /api/v1/contato/verificar x-api-key

Higienização em lote de listas com resolução automática do nono dígito brasileiro. Testa se o número existe com ou sem o 9 (ex: 55119... vs 5511...) e retorna o JID exato registrado no servidor do WhatsApp. 

curl -X POST https://wooapi.wootech.com.br/api/v1/contato/verificar \
  -H "Content-Type: application/json" \
  -H "x-api-key: SUA_CHAVE_DE_INSTANCIA" \
  -d '{
    "numeros": ["(11) 98765-4321", "62988887777", "551999998888"]
  }'

POST /api/v1/instancia/{id}/configuracoes Bearer Token

Blindagem e proteção da linha telefônica: IP dedicado via Proxy Residencial SOCKS5/HTTP, rejeição automática de ligações de voz/vídeo com resposta configurável e modo sempre online. 

curl -X POST https://wooapi.wootech.com.br/api/v1/instancia/inst_abc123/configuracoes \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer SEU_TOKEN_JWT" \
  -d '{
    "proxy_url": "socks5://usuario:senha@proxy-brasil.provedor.com:1080",
    "rejeitar_chamadas": true,
    "mensagem_chamada_rejeitada": "Olá! Não atendemos ligações por este canal. Por favor, envie uma mensagem de texto.",
    "ignorar_grupos": false,
    "leitura_automatica": true,
    "sempre_online": true
  }'
MCP SPEC Model Context Protocol (MCP) • Guia de Conexão com IA

O Model Context Protocol (MCP) é o padrão aberto que conecta assistentes de inteligência artificial (como Claude, Cursor, Antigravity, VS Code e agentes autônomos) a sistemas externos. Através do MCP da WooHub API, IAs podem executar ações de WhatsApp nativamente sob linguagem natural.

Ferramentas (Tools) Expostas para a IA:

Ferramenta (Tool) Parâmetros Principais Ação Realizada pelo Agente de IA
whatsapp_send_text destinatario, mensagem, atraso_ms Envia texto simples ou com formatação e delay humano.
whatsapp_send_media destinatario, tipo, url, legenda Envia áudios gravados na hora (PTT), imagens, vídeos ou faturas PDF.
whatsapp_send_poll destinatario, pergunta, opcoes Cria enquetes de decisão e pesquisa para os clientes responderem.
whatsapp_verify_number numeros (array) Higieniza telefones e corrige automaticamente o 9º dígito brasileiro.
whatsapp_get_status instancia_id Verifica se o WhatsApp está conectado, nível de bateria e versão.

Configuração no Claude Desktop / Cursor / Antigravity:

Adicione o bloco abaixo ao arquivo claude_desktop_config.json ou na configuração de MCP Servers da sua IDE: 

{
  "mcpServers": {
    "woohub-whatsapp": {
      "command": "npx",
      "args": ["-y", "@woohub/mcp-server"],
      "env": {
        "WOOHUB_API_URL": "https://wooapi.wootech.com.br",
        "WOOHUB_API_KEY": "SUA_CHAVE_DE_INSTANCIA_AQUI"
      }
    }
  }
}
